# THE BOYZ SCHEDULE — mobile edition

Samodzielna strona GitHub Pages z kalendarzem THE BOYZ.

## Zmiany w tej wersji

- miesięczny kalendarz mieści się w całości na ekranie telefonu bez poziomego przewijania;
- zachowane widoki tygodnia, dnia i listy;
- miniatury wydarzeń w kalendarzu, liście, widoku dnia/tygodnia i sekcji Upcoming;
- rozbudowane opisy wydarzeń z nagłówkami, akapitami i obrazami;
- publiczny widok pozostaje tylko do odczytu.

Wydarzenia edytujesz w `data/events.js`. Obrazy możesz wgrywać do `assets/events/`.

## Zachowanie na urządzeniach mobilnych

Widok miesięczny mieści wszystkie siedem kolumn na ekranie. Widok tygodniowy zachowuje czytelne kolumny dni i jest przewijany poziomo. Nagłówek pozostaje w normalnym układzie strony i nie przykrywa treści.
